Real-Time Exchange Rates

Currency Convert Breeze

A chainable PHP library for real-time currency conversion with exchange rates from exchangerate-api.com. Convert amounts between multiple currencies with session-based caching and flexible output formats.

Get Started GitHub Repository
00 / Overview

Why Currency Breeze?

Chainable API

Fluent interface for setting currencies and amounts with intuitive method chaining.

Session Caching

Automatic exchange rate caching reduces API calls and improves performance.

Multiple Targets

Convert to multiple currencies in a single operation with array syntax.

Flexible Output

Get results as arrays or JSON with consistent error handling.

01 / Getting Started

Installation

Via Composer

Install Currency Convert Breeze using Composer:

bash
composer require breeze_converter/currency

Session Setup

Ensure PHP sessions are enabled (required for exchange rate caching):

php
require 'vendor/autoload.php';
// Sessions are used for caching
session_start();
use converter\Converter;
02 / Core Methods

API Reference

from()

Set the base currency for conversion.

$converter->from(string $currency)
Parameters:

$currency - Currency code (e.g., 'USD', 'EUR', 'GBP')

to()

Set target currencies to convert to.

$converter->to(array $currencies)
Parameters:

$currencies - Array of currency codes: ['EUR', 'GBP', 'CAD']

amount()

Set the amount to convert.

$converter->amount(float|int $amount)
Parameters:

$amount - Numeric value to convert

run()

Execute the conversion and return results.

$converter->run(string $format = 'json')
Parameters:

$format - Output format: 'json' or 'array'

baseCurrency()

Set default base currency (used if from() not called).

$converter->baseCurrency(string $currency)

defaultAmount()

Set default amount for conversions.

$converter->defaultAmount(float|int $amount)

expiry()

Set session cache expiry time in seconds.

$converter->expiry(int $seconds)
Default:

300 seconds (5 minutes)

03 / Practical Examples

Real-World Usage

Basic Currency Conversion

Convert 100 USD to EUR and GBP.

php
try {
  $converter = new Converter();
  $result = $converter
    ->from('USD')
    ->to(['EUR', 'GBP'])
    ->amount(100)
    ->run('json');
  echo $result;
} catch (Exception $e) {
  echo 'Error: ' . $e->getMessage();
}
Response
{
  "status": "success",
  "values": {
    "EUR": 93.50,
    "GBP": 83.20
  }
}

  ->amount(100)
  ->run('array');
print_r($result);
Response
Array
(

Convert to Multiple Currencies

Convert 50 CAD to multiple target currencies in one call.

php
$result = $converter
  ->from('CAD')
  ->to([
    'USD', 'EUR', 'GBP',
    'JPY', 'AUD', 'NGN'
  ])
  ->amount(50)
  ->run('json');
Response
{
  "status": "success",
  "values": {
    "USD": 36.75,
    "EUR": 34.40,
    "GBP": 30.50,
    "JPY": 5687,
    "AUD": 56.25,

Error Handling

Handle invalid currency codes and API failures gracefully.

php
$result = $converter
  ->from('USD')
  ->to(['INVALID'])
  ->amount(100)
  ->run('json');
echo $result;
Error Response
{
  "status": "error",
  "message": "Currency conversion rate for INVALID not available."
}

Using Default Settings

Set default currencies and amounts for reusable converter instances.

php
$converter = new Converter();
// Set defaults
$converter
  ->baseCurrency('CAD')
  ->defaultAmount(100)
  ->expiry(600); // 10 min cache
// Now just specify targets
$result = $converter
  ->to(['USD', 'EUR'])
  ->run('json');
Result
✓ Uses CAD (default)
✓ Uses 100 (default amount)
✓ Cache set to 600s

{
  "status": "success",
  "values": {
    "USD": 73.5,
    "EUR": 68.8
  }
}

Constructor with Configuration

Set defaults directly in the constructor.

php
$converter = new Converter([
  'basecurrency' => 'GBP',
  'defaultamount' => 50,
  'cookieexpiry' => 300
]);
$result = $converter
  ->to(['USD', 'EUR'])
  ->run('json');
Result
Converter initialized with:
- Base: GBP
- Default: 50
- Cache: 5 min

{
  "status": "success",
  "values": {
    "USD": 63.20,
    "EUR": 59.10
  }
}
04 / Configuration & Caching

Default Settings & Optimization

Configure default behavior and optimize caching for your use case.

Default Values Reference

Setting Default Value Method Description
Base Currency USD baseCurrency('CAD') Currency used when from() not called
Default Amount 1 defaultAmount(100) Amount used when amount() not called
Cache Expiry 300s (5 min) expiry(600) Session cache duration in seconds

Caching Strategies

Fast Cache (5 min)

expiry(300) - Good for real-time rate updates. Use for trading/forex applications.

Medium Cache (10-15 min)

expiry(600-900) - Balanced approach. Suitable for e-commerce & most apps.

Long Cache (30 min+)

expiry(1800+) - Minimal API calls. Use for background jobs & reports.

No Cache (0)

expiry(0) - Always fresh rates. Use sparingly to avoid hitting API limits.
