Lightweight JSON Library

JBreeze

Seamless manipulation, querying, and handling of JSON data with an intuitive, chainable API. Filter, update, insert, delete, and sort data directly from JSON files or raw JSON strings.

Get Started GitHub Repository
01 / Key Features

Why JBreeze?

Chainable API

Fluent interface for elegant, readable code with method chaining.

Advanced Filtering

Filter with operators (>, <,=, %, etc.) and support for nested keys using dot notation.

File & String Support

Load data from JSON files or raw JSON strings seamlessly.

Zero Dependencies

Lightweight library with no external dependencies. Simple to integrate.

02 / Getting Started

Installation

Via Composer

Install JBreeze using Composer (recommended):

bash
composer require jbreeze/jbreeze

Basic Setup

After installation, require the autoloader and start using JBreeze:

php
require 'vendor/autoload.php';
use jbreeze\jbreeze;
$jbreeze = new jbreeze();
03 / Core Methods

Available Methods

data()

Load JSON data from a file, raw JSON string, or URL.

$jbreeze->data(string $input)
Parameters:

$input - Path to JSON file, raw JSON string, or URL

where()

Filter data by exact match OR comparison. Use operators as string values.

$jbreeze->where(array $conditions)
Parameters:

$conditions - Array with field => value (or "field" => "operator:value")

select()

Select specific fields from results.

$jbreeze->select(array $keys = [])
Parameters:

$keys - Array of field names to include

order()

Sort results by a field in ascending or descending order.

$jbreeze->order(string $field, string $direction = 'DESC')
Parameters:

$field - Field name to sort by

$direction - 'ASC' or 'DESC' (default: DESC)

limit()

Limit the number of results returned.

$jbreeze->limit(int $count)
Parameters:

$count - Maximum number of records

insert()

Insert a new record into the JSON data.

$jbreeze->insert(array $data, string $primaryKey = null)
Parameters:

$data - Associative array of the new record

$primaryKey - Optional field to auto-increment

update()

Update records matching the where() condition.

$jbreeze->update(array $data)
Parameters:

$data - Fields to update

delete()

Delete records matching the where() condition.

$jbreeze->delete()

find()

Find first record matching key-value pair.

$jbreeze->find(string $key, mixed $value)

between()

Filter by numeric range [min, max].

$jbreeze->between(string $field, array $range)

run()

MUST call this to execute the query. Returns JSON or array.

$jbreeze->run(string $returnType = 'json')
04 / Practical Examples

Real-World Usage

Filter & Update Users

Load users.json, filter active users, add new user, and update status.

php
$jbreeze = new jbreeze();
$jbreeze->data('users.json');
// Get active users
$active = $jbreeze
  ->where(['status' => 'active'])
  ->order('name', 'ASC')
  ->run('array');
Response
[
  {
    "id": 1,
    "name": "Alice",
    "status": "active"
  },
  {
    "id": 3,
    "name": "Charlie",
    "status": "active"
  }
]
php
// Add new user with ID
$jbreeze->insert([
  'name' => 'Diana',
  'status' => 'active'
], 'id')->run();
Result
New record inserted
ID: 4 (auto-incremented)
php
// Update user status
$jbreeze->where(['id' => 1])
  ->update(['status' => 'inactive'])
  ->run();
Updated Record
{
  "id": 1,
  "name": "Alice",
  "status": "inactive"
}

Product Search with Filters

Find electronics priced 10-100, in stock, sorted by price, limit 3.

php
$jbreeze->data('products.json');
$products = $jbreeze
  ->where(['category' => 'Electronics'])
  ->between('price', [10, 100])
  ->where(['stock' => '>0'])
  ->order('price', 'ASC')
  ->limit(3)->run('array');
Response
[
  {
    "id": 5,
    "name": "USB Cable",
    "price": 12,
    "stock": 50
  },
  {
    "id": 2,
    "name": "Headphones",
    "price": 45,
    "stock": 20
  }
]

Nested Data with Dot Notation

Filter users by nested address.city and update nested fields.

php
$json = '[
  {"id":1,"name":"John",
  "address":{"city":"Lagos"}},
  {"id":2,"name":"Jane",
  "address":{"city":"Abuja"}}
]';
$jbreeze->data($json);
// Filter by nested field
$lagosUsers = $jbreeze
  ->where(['address.city' => 'Lagos'])
  ->run();
Response
{
  "id": 1,
  "name": "John",
  "address": {
    "city": "Lagos"
  }
}
php
// Select nested fields
$selected = $jbreeze
  ->select(['name', 'address.city'])
  ->run();
Response
[
  {
    "name": "John",
    "address": {
      "city": "Lagos"
    }
  },
  {
    "name": "Jane",
    "address": {
      "city": "Abuja"
    }
  }
]
php
// Update nested field
$jbreeze->where(['address.city' => 'Lagos'])
  ->update([
    'address.city' => 'Lagos Island'
  ])->run();
Updated
{
  "id": 1,
  "name": "John",
  "address": {
    "city": "Lagos Island"
  }
}
05 / Key Takeaways

Best Practices

Always Call run()

Chain methods and call ->run() at the end to execute the query.

Use Dot Notation

Access nested fields with 'parent.child.grandchild' syntax.

Operators as String Values

where(['age' => '>25']) — the operator comes after the field name in the value.

Method Chaining

Combine where(), select(), order(), limit() in one fluent expression.
