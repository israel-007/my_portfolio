Fluent Excel API

fluentXLSX

A fluent, developer-friendly PHP library that unifies reading and writing Excel files. Built on SimpleXLSX and SimpleXLSXGen with a clean, expressive API for seamless XLSX manipulation.

Get Started GitHub Repository
00 / Overview

Why fluentXLSX?

Unified API

Read and write Excel files with a single, consistent API — no switching libraries.

Fluent Interface

Chain methods for elegant, readable code. Build complex Excel operations with ease.

Battle-Tested

Built on SimpleXLSX & SimpleXLSXGen — stable, production-ready foundations.

Multi-Sheet Support

Create, read, and manage multiple sheets with intuitive methods.

01 / Getting Started

Installation

Via Composer

Install fluentXLSX using Composer:

bash
composer require fluentxlsx/fluentxlsx

Basic Setup

After installation, require the autoloader and start using fluentXLSX:

php
require 'vendor/autoload.php';
use Fluentxlsx\Excel;
// Start reading or writing
02 / Reading Excel Files

Extract Data from XLSX

Read from File

Open an Excel file and retrieve all rows from the first sheet.

php
$reader = Excel::read('users.xlsx')
  ->sheet(0);
$rows = $reader->rows();
Response
[
  ["ID", "Name", "Email"],
  [1, "Alice", "alice@ex.com"],
  [2, "Bob", "bob@ex.com"]
]

Select Sheet by Name or Index

Navigate between multiple sheets in a single workbook.

php
// By index (0-based)
$sheet0 = Excel::read('data.xlsx')
  ->sheet(0);
Result
First sheet selected
php
// By name
$users = Excel::read('data.xlsx')
  ->sheet('Users');
Result
Sheet named "Users" selected
php
// Active sheet
$active = Excel::read('data.xlsx')
  ->sheet('ACTIVE');
Result
Currently active sheet loaded

Extract Headers

Retrieve column headers from the first row.

php
$reader = Excel::read('users.xlsx')
  ->sheet(0);
$headers = $reader->headers();
Response
[
  "ID",
  "Name",
  "Email"
]

Limit & Range Rows

Retrieve specific rows or a range of rows.

php
// First 5 rows
$rows = $reader->rows(5);
Response
5 rows returned
Including header row
php
// Rows 2 to 10 (1-based, inclusive)
$range = $reader->rows([2, 10]);
Response
[
  [1, "Alice", ...],
  [2, "Bob", ...],
  ...
]
9 rows total
php
// Explicit rows: 1, 3, 5
$rows = $reader->rowsEx([1, 3, 5]);
Response
[
  ["ID", "Name", ...],
  [1, "Alice", ...],
  [3, "Charlie", ...]
]

Convert to Associative Array

Map headers as keys for easier data access.

php
$assoc = $reader->toAssoc();
print_r($assoc[0]);
Response
Array
(
  [id] => 1
  [name] => Alice
  [email] => alice@ex.com
)

Get Cell by Reference

Access individual cells by Excel notation or row/column indices.

php
// By Excel reference (e.g., B3)
$value = $reader->cell('B3');
echo $value; // "Alice"
Response
"Alice"
php
// By row/column (1-based)
$value = $reader->cellEx(3, 'B');
echo $value;
Response
"Alice"

Get All Sheet Names

List all sheets available in the workbook.

php
$sheets = $reader->sheets();
print_r($sheets);
Response
Array
(
  [0] => "Users"
  [1] => "Products"
  [2] => "Orders"
)
03 / Writing Excel Files

Create & Modify XLSX

Write Basic Sheet

Create an Excel file with a single sheet and save it.

php
Excel::write()
  ->addSheet('Users', [
    ['ID', 'Name', 'Email'],
    [1, 'John', 'john@ex.com'],
    [2, 'Jane', 'jane@ex.com']
  ])
  ->save('users.xlsx');
Result
✓ File created: users.xlsx

Sheet "Users" added with:
- 1 header row
- 2 data rows
A B C
ID Name Email
1 John john@ex.com
2 Jane jane@ex.com

Create Multiple Sheets

Build a workbook with several sheets in one operation.

php
Excel::write()
  ->addSheet('Users', [
    ['ID', 'Name'],
    [1, 'Alice']
  ])
  ->addSheet('Products', [
    ['ID', 'Product'],
    [1, 'Laptop']
  ])
  ->save('data.xlsx');
Result
✓ File created: data.xlsx

Sheets:
- Users
- Products

Write Individual Cells

Place values at specific cell locations using Excel notation.

php
// By Excel reference
Excel::write()
  ->cell('A1', 'Hello')
  ->cell('B2', 123)
  ->cell('C3', '=SUM(B2:B10)')
  ->save('cells.xlsx');
Result
✓ File created

A1: "Hello"
B2: 123
C3: =SUM(B2:B10)
php
// By row/column index
Excel::write()
  ->cellEx(3, 'B', 'Price')
  ->cellEx(4, 3, 100)
  ->save('data.xlsx');
Result
✓ B3: "Price"
✓ C4: 100

Write Rows

Add complete rows or batch data to the sheet.

php
// Single row
Excel::write()
  ->addRow(['Name', 'Email'])
  ->addRow(['John', 'john@ex.com'])
  ->save('contacts.xlsx');
Result
2 rows written
php
// Multiple rows at once
Excel::write()
  ->rows([
    ['ID', 'Score'],
    [1, 90],
    [2, 85]
  ])
  ->save('scores.xlsx');
Result
3 rows written at once

Save & Download

Output Excel files for saving locally or direct download.

php
// Save to file
Excel::write()
  ->addSheet('Data', [...])
  ->save('output.xlsx');
Result
✓ File saved to disk
output.xlsx created
php
// Download from browser
Excel::write()
  ->addSheet('Report', [...])
  ->download('report.xlsx');
Result
Browser download triggered
report.xlsx
(Content-Disposition: attachment)
php
// Get binary data
$data = Excel::write()
  ->addSheet('Users', [...])
  ->toString();
// Send as email attachment
Result
Binary string returned
Ready to attach to
email or API response
04 / Real-World Examples

Practical Workflows

Read, Transform & Write

Load data, convert to associative array, filter, and save to new file.

php
// Read & convert
$data = Excel::read('users.xlsx')
  ->toAssoc();
// Filter active users
$active = array_filter($data,
  fn($u) => $u['status'] === 'active'
);
// Write filtered data
Excel::write()
  ->rows($active)
  ->save('active_users.xlsx');
Flow
1. Read users.xlsx
2. Convert to assoc array
{
  "name": "Alice",
  "status": "active"
}
3. Filter active rows
4. Write to active_users.xlsx
✓ Done

Combine Multiple Sheets

Read from two sheets and merge into one output file.

php
// Read both sheets
$file = Excel::read('data.xlsx');
$users = $file->sheet(0)->rows();
$products = $file->sheet(1)->rows();
// Write to new file
Excel::write()
  ->addSheet('Users', $users)
  ->addSheet('Products', $products)
  ->save('combined.xlsx');
Result
combined.xlsx created

Sheets:
✓ Users
✓ Products

All data preserved
05 / Best Practices

Key Takeaways

Method Chaining

Chain methods for fluent, readable code. Each call returns the writer/reader object.

Sheet Selection

Select sheets by index, name, or 'ACTIVE'. Works intuitively for multi-sheet files.

Data Transformation

Use toAssoc() to map headers as keys for easier programmatic access.

Direct Access

Use underlying SimpleXLSX/SimpleXLSXGen methods for advanced features.
